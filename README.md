# ICU AI 教练（PWA）

一个接入 [Intervals.icu](https://intervals.icu) 的个人 AI 骑行教练：
- **可分析**：读你的训练记录、CTL/ATL/Form、恢复状态，生成训练复盘
- **可回写**：AI 生成课表，一键写回 Intervals.icu 日历，同步码表即练
- **模型可替换**：改环境变量即可切换 DeepSeek / 豆包方舟 / OpenAI / Kimi 等，不用改代码
- **手机可用**：PWA 网页应用，iPhone/安卓都能「添加到主屏」，像原生 App
- **每日建议**：每天自动生成「今日训练建议」贴在概览页（也写入 ICU 当天日历便签）；复盘依然每次课后在复盘页做
- **内置训练判断原则**：负荷看绝对值、EF/VI 趋势、恢复数据优先、训练空窗提醒；复盘可只统计骑行（排除徒步污染负荷）
- **内置「训练科学知识卡」**：蒸馏自开源训练知识库「人类耐力变强计划」（human-upgrade-plan，作者张张的鞋）——睡眠与生病闸门、空气质量（PM2.5）、HRV 用法、间歇组间休息与阈值训练原则、天气与体感调整等，复盘/课表/对话/每日建议都按这些原则判断

## 一、整体结构

```
icucoach/
├── api/           云端函数（Vercel Serverless）
│   ├── overview.js     读概况（FTP/体重/CTL/ATL/Form/Readiness）
│   ├── coach.js        复盘 + 生成课表（调用大模型）
│   └── workouts.js     把课表写回 ICU
├── lib/
│   ├── icu.js          Intervals.icu API 客户端
│   ├── llm.js          可替换的大模型客户端
│   └── prompts.js      教练提示词
├── public/         前端 PWA（手机界面 + 离线缓存 + 主屏图标）
└── .env.example    环境变量模板
```

**安全说明**：ICU API Key 推荐直接在 App「设置」页填写，只保存在你自己设备的浏览器里，请求时直接发给自己的后端去调 ICU，不会上传到别处；服务器环境变量只作为兜底（页面没填时使用）。大模型密钥只存在服务器环境变量里。

## 二、准备：生成 ICU API Key

1. 打开 Intervals.icu 并登录，进入 **Settings（设置）→ Developer / API**。
2. 生成一个 API Key（读写权限），复制保存好。
3. 记下你的运动员 ID：个人主页链接里的数字，例如 `.../athlete/i464783` 中的 `464783`。

## 三、部署到 Vercel（免费）

### 方式 A：从 GitHub 导入（推荐，你熟悉 GitHub）

1. 把整个 `icucoach` 文件夹推到一个新的 GitHub 仓库（`package.json` 在仓库根目录）。
2. 打开 [vercel.com](https://vercel.com)，用 GitHub 账号登录。
3. 点 **Add New → Project**，选中这个仓库，直接 **Deploy**（Vercel 会自动识别）。
4. 部署完成后，进入项目的 **Settings → Environment Variables**，添加下面的环境变量。

### 方式 B：用 Vercel CLI

```bash
npm i -g vercel
cd icucoach
vercel          # 首次会引导登录
vercel --prod   # 部署到正式环境
```

## 四、配置环境变量（关键一步）

**ICU 相关变量和模型密钥都可以在 App「设置」页直接填（推荐，改起来方便、只存手机浏览器），服务器里不必配。** 强烈建议在 Vercel 配一个 `ACCESS_TOKEN`（访问口令），并同样填到 App「设置」页——防止陌生人打开你的网址白嫖模型额度。在 Vercel 项目的 **Settings → Environment Variables** 里添加，然后点 **Redeploy**：

| 变量名 | 值 | 必填 |
|---|---|---|
| `ACCESS_TOKEN` | 一串只有你知道的随机字符（App「设置」页要填同一个） | 强烈建议 |
| `ICU_API_KEY` | Intervals.icu API Key（推荐在 App「设置」页填；此变量仅作兜底） | 二选一 |
| `ICU_ATHLETE_ID` | 运动员 ID（如 `464783`；也可在 App「设置」页填，页面优先） | 可选 |
| `LLM_PROVIDER` | `deepseek` / `volcano` / `openai` / `moonshot` / `custom`（推荐在 App「设置」页选） | 按需 |
| `DEEPSEEK_API_KEY` | 用 DeepSeek 时填（推荐在 App「设置」页填） | 按需 |
| `VOLCANO_API_KEY` | 用豆包方舟时填 | 按需 |
| `OPENAI_API_KEY` | 用 OpenAI 时填 | 按需 |
| `MOONSHOT_API_KEY` | 用 Kimi 时填 | 按需 |
| `CUSTOM_API_KEY` | 用其它 OpenAI 兼容服务时填 | 按需 |
| `CRON_SECRET` | 定时任务用，一串随机字符（可选，配了 Cron 就建议填） | 可选 |

> 完整模板见 `.env.example`。`custom` 或 `volcano` 类型还需额外填 `LLM_BASE_URL` 和 `LLM_MODEL`（火山填「推理接入点 ID」）。
> 只有想用「每天早上定时预生成今日建议」时，才必须把 ICU Key 和模型密钥配在服务器（定时任务读不到手机浏览器里的设置）；不配也不影响使用，打开 App 时会兜底生成。

### 换模型示例

- 想从 DeepSeek 换成豆包方舟：App「设置」页把服务商选成「火山方舟（豆包）」、填模型密钥和接入点 ID，保存即可（服务器不用动）；或者改服务器环境变量 `LLM_PROVIDER=volcano`、填 `VOLCANO_API_KEY`，再加 `LLM_MODEL=ep-你的接入点ID`。**代码一个字都不用改。**

## 五、每日建议（定时任务）

- **自动兜底**：打开 App 时，如果今天还没有建议，会在后台自动生成（约十几秒，生成后点「刷新」可见）。不配定时任务也能用。
- **定时预生成（可选）**：项目里已配好 Vercel Cron（每天 UTC 00:00 = 北京时间 08:00 触发）。需要 `ICU_API_KEY` 配在 Vercel 环境变量里（因为定时任务读不到你手机里填的 Key）。可选加一个 `CRON_SECRET` 随机串作为安全校验。
- 生成的建议会同时作为一条「AI 今日建议」便签写进你 ICU 当天的日历，ICU 网页端也能看到。

## 七、使用流程

1. **概览**：顶部是「今日建议」（每天自动生成，练前看）；下面是当前体能（CTL）、疲劳（ATL）、状态（Form）、FTP、体重、Readiness、距上次训练。
2. **复盘**：选回看天数 + 想关注的问题 → 生成复盘，教练给出状态判断、关键发现、风险提示和后续建议。
3. **课表**：默认「今天（可选课表）」模式——生成低/中/高 3 节课，按当天体感选一节写回 ICU（经 ICU → Garmin Connect 自动推送到码表）；也可切换 5/7/14 天批量生成。
4. **对话**：右下角浮动按钮，任意页面随时打开与 AI 教练聊天。教练会「动手干活」：
   - 说「复盘我昨天的课」→ 拉取该课深度数据（分段/NP/VI/EF/心率漂移/HRRc）做单课复盘，复盘完自动标记「AI复盘已完成」，下次自动跳过；
   - 说「帮我写一节甜区课并写入 ICU」→ 直接生成结构化课表并写入 ICU 日历（同步码表）；
   - 已标记的活动在复盘页也只做趋势参考。
   聊天记录存在本机浏览器，可一键清空。
5. **设置**：填 ICU API Key（存本机，随时可换）、运动员 ID（可选，覆盖服务器配置）、AI 模型服务商与模型密钥（同样存本机，换模型不用动服务器）、访问口令（与服务器 `ACCESS_TOKEN` 一致，防陌生人调用）、自定义教练人设，或粘贴整段自定义提示词。写几句想法点「AI 自动扩展优化」，可让 AI 帮你扩写成完整提示词。还可设置「教练记忆保留天数」（默认 48 天，7-365 可调）。

**Q：我有一大段提示词（人设+复盘+课表规则都写在一起），怎么用？**
粘贴到 App「设置 → 自定义提示词」，保存即可。它会整体替换内置提示词和「教练人设」。每次运行时，系统会自动把当天的真实数据（FTP/体重/最大心率、CTL/ATL/Form、恢复状态、最近训练记录）拼在提示词后面一起喂给模型，你不需要在提示词里写数据。注意：生成课表时系统会额外附加一段 JSON 输出格式要求（保证课表能写回 ICU），这段不用你自己写。

## 八、常见问题

**Q：概览页某几项显示「—」或报错？**
说明那个数据项拿不到（比如没开 Readiness），不影响其它功能。

**Q：写回课表后 ICU 里功率区间对不对？**
ICU 会自动解析 workout 文本并计算 TSS/区间，你在 ICU 日历点开该课即可核对。若某节课不满意，可在 ICU 里直接删改，或重新生成。

**Q：教练有记忆吗？会不会越用越懂我？**
有。教练在 ICU 里维护一条「AI 教练记忆」便签：每次复盘后自动把值得长期记住的结论追加进去（用户特征、训练偏好、重要结论、伤病等），对话中遇到重要信息它也会自己记。之后每次对话、复盘、每日建议都会自动带上这些记忆，所以越用越懂你。记忆跟着 ICU 账号走，换手机不丢；可在 App「设置」改保留天数（默认 48 天，超过自动清除）；也可以直接在 ICU 日历里打开这条便签查看或删除。

**Q：换了 ICU API Key，怎么改？**
打开 App「设置」页重新输入新 Key，保存即生效，服务器不用动。旧 Key 会立即被新 Key 覆盖。

**Q：换手机了，Key 和设置还在吗？**
设置存在本机浏览器里，不跟账号走。新手机重新填一次即可。

**Q：「今天（可选课表）」模式怎么用？**
生成 3 节强度低/中/高的当天可选课（如恢复骑、甜区、阈值），按当天体感点「选这节」，再点「写回 ICU」。写回后走 ICU → Garmin Connect 自动推送（需已授权并开启「上传计划中的训练课程」；Garmin 一般只接收未来 7 天内的计划课）。

**Q：复盘里的「只看骑行」开关是干什么的？**
排除徒步等非骑行活动。例如一次长徒步 TSS 400+ 会把 ATL 顶得很高、把 Form 打进红色，但它不反映骑行体能。勾上后复盘只统计 Ride/VirtualRide，判断更准。

**Q：想用更强的模型？**
改 `LLM_PROVIDER` 和对应密钥即可，提示词已做通用化处理。

**Q：网址是公开的，别人打开会不会白嫖我的模型额度？**
不会。在 Vercel 环境变量配一个 `ACCESS_TOKEN`（任意随机串），再在 App「设置 → 访问口令」填同一个值，所有接口都会校验口令，对不上直接拒绝；另外后端还有简单的限流（同一口令 10 分钟最多 120 次请求）兜底。模型密钥只存你手机浏览器，就算有人打开页面也拿不到你的密钥。

**Q：教练的训练知识从哪来？**
内置一张「训练科学知识卡」，蒸馏自开源训练知识库「人类耐力变强计划」（GitHub：`97657407-cmd/human-upgrade-plan`，作者张张的鞋，约 358 条文献索引）。我们只提炼了与骑行相关的通用原则（睡眠/生病闸门、PM2.5 空气质量、HRV 用法、间歇休息、阈值训练、天气体感、恢复与生活），没有引入跑者配速等不适用内容。知识库原文单独保存在本地参考库，想更新时用 `git pull` 拉最新版，再提炼新要点即可。

**Q：本地怎么跑起来调试？**
```bash
cd icucoach
cp .env.example .env      # 填好你的密钥
vercel dev                # 本地起服务，浏览器打开 localhost:3000
```
